# 要件定義: Sleep Tracker(睡眠トラッカーアプリ)


## 1. 目的・前提
- スマホのマイクで一晩の睡眠を記録・解析し、睡眠スコア/ステージ/いびき/無呼吸/寝言を可視化する。
    - 必須要件。
- スマートアラーム、睡眠導入サウンド、ウォッチ連携を提供する。
    - 必須要件拡充後に対応。

## 2. 機能要件
### FR-1 オンボーディング
下記はアプリの機能に必要なものだけ実装する
- FR-1.1 起床時刻・就寝時刻を質問し、リマインダーを自動設定する。
- FR-1.2 利用目的(睡眠記録/入眠改善/睡眠の質向上/朝を楽に/生活リズム)を複数選択できる。
- FR-1.3 マイク・ストレージ権限の用途を説明して取得する。
- FR-1.4 就寝〜起床の睡眠時間が 1〜20 時間になるよう入力を制限する。
- FR-1.5 性別・生年月日などの追加プロフィールを任意で取得する。

### FR-2 睡眠計測
- FR-2.1 ホームから就寝/アラーム時刻を設定し「睡眠開始」で計測を開始できる。
- FR-2.2 計測中はフォアグラウンドサービスで一晩マイク録音を継続する。
- FR-2.3 画面モードを選択できる(自動ロック / 画面を暗くする)。
- FR-2.4 開始前に充電・電池残量(50% 未満で警告、30% 以上推奨)、スマホの置き場所、通知/正確なアラーム権限、バッテリー最適化除外を案内する。
- FR-2.5 マイクが他アプリに占有されている場合は通知し、計測を一時停止する。
- FR-2.6 スリープサウンド再生中はいびき録音を一時停止する。
- FR-2.7 セッション時間による扱い: 10 分未満=保存しない / 10〜30 分=Short Sleep(分析対象外)/ 30 分以上=通常分析 / 4 時間以上=睡眠スコア対象。
- FR-2.8 終了時に Discard / Short Sleep として保存 / 計測継続 を選択できる。
- FR-2.9 電池切れ・アプリ終了・OS による kill 等の中断を検知し、次回起動時に通知・ダイアログで中断と原因を案内する(データが不正確な旨も表示)。
- FR-2.10 計測前に睡眠前メモ・タグ(最大 20 文字、重複不可)を記録できる。
- FR-2.11 起床時に気分(5 段階)を記録できる。

### FR-3 アラーム・リマインダー
- FR-3.1 通常アラーム / スマートアラーム(設定期間内の浅い睡眠で起床)/ インテリジェントスヌーズ / アラームなしを選べる。
- FR-3.2 スヌーズ時間・起床期間を設定できる。シェイクでスヌーズ、長押しで起床停止。
- FR-3.3 計測サービスが停止してもアラームが鳴るバックアップアラームを持つ。
- FR-3.4 就寝リマインダー(30 分経過後も未計測ならフォロー)、昼寝、充電、置き場所リマインダーを提供する。
- FR-3.5 起床アニメーション・壁紙を選択できる。

### FR-4 睡眠解析・スコア
- FR-4.1 睡眠ステージ(Deep / Light / REM / Awake)を判定し、睡眠曲線で表示する。
- FR-4.2 睡眠時間、入眠潜時、Time in bed、各ステージ長/割合、覚醒回数、睡眠負債、就寝/起床のばらつきを算出する。
- FR-4.3 睡眠スコア 2.0 を Duration / Restoration / Consistency / Feeling の 4 要素で算出し、Excellent / Pretty Good / Fair / Poor に区分する。(計算式は)
- FR-4.4 スコアが生成されない場合、理由を説明するページを表示する。
- FR-4.5 いびき: 頻度・最大/平均 dB・時間・発生時刻を記録する。
- FR-4.6 無呼吸: 頻度・重症度レベル・最大/合計継続時間を記録し、リスクを通知する。
- FR-4.7 音声イベント(いびき/寝言/咳/歯ぎしり/おなら/足音/動物/環境音)を分類し録音クリップとして保存する。
- FR-4.8 クリップの再生・再分類・ダウンロード・削除・動画共有ができる。
- FR-4.9 8 種の睡眠動物タイプ診断(Lark/Owl/Bear/Cat/Fox/Lion/Rabbit/Sloth)と Tips を表示する。
- FR-4.10 5 日睡眠チャレンジ達成で睡眠動物を判定する演出を表示する。

### FR-5 統計
- FR-5.1 Journal(日)/ Week / Month の表示切替。
- FR-5.2 平均睡眠・就寝・起床、平均いびき、最大音量などの集計を表示する。
- FR-5.3 睡眠前要因・曜日・天気と睡眠の相関を表示する(データ不足時はその旨を表示)。
- FR-5.4 記録の削除・Discard・画像エクスポート/共有ができる。

### FR-6 Discover(サウンド・音楽)
- FR-6.1 睡眠サウンド(250+ 種)、睡眠音楽、瞑想、ストーリーを閲覧・再生できる。
- FR-6.2 複数の音を組み合わせたミックスを作成・命名・保存・並び替え・プリセットへ戻す操作ができる(選択数に上限)。
- FR-6.3 お気に入り登録、おすすめ表示ができる。
- FR-6.4 再生タイマー(終了時フェードアウト)、バックグラウンド再生ができる。
- FR-6.5 コンテンツはダウンロード式で、キャッシュ削除ができる。
- FR-6.6 無料/Premium でコンテンツを出し分ける。

### FR-7 ウォッチ・ヘルス連携
- FR-7.1 Fitbit と OAuth 連携し睡眠データを同期する(接続成功/失敗/タイムアウトの状態表示)。
- FR-7.2 Health Connect 経由で Samsung 等の睡眠データを読み取り同期する(同期中/成功/失敗の状態表示)。
- FR-7.3 連携ソースの選択、同期設定、同期 FAQ を提供する。
- FR-7.4 Google Fit 連携の接続/切断。

### FR-8 設定・アカウント
- FR-8.1 プロフィール(性別/生年月日/身長/体重/単位 Metric・Imperial)。
- FR-8.2 睡眠設定(目標睡眠時間、日の区切り時刻など)。
- FR-8.3 言語切替(18 言語)、12/24 時間形式。
- FR-8.4 権限アシスタント(自動起動・バッテリー最適化・通知・バックグラウンド表示をベンダー別に案内)。
- FR-8.5 Google サインインによるバックアップ・復元。(Facebook 同期は廃止)
- FR-8.6 キャッシュ削除、全データ削除(クラウド含む)。
- FR-8.7 フィードバック送信(睡眠ログ添付可)、FAQ、アプリ評価依頼、共有、プライバシー/利用規約。

## 3. 非機能要件
- NFR-1 常駐性: 最長 20 時間のマイク録音を継続(WakeLock、フォアグラウンドサービス、サービス相互起動、バックアップアラーム、OEM 電力管理の誘導)。
- NFR-2 省電力: 電池 30% 以上を推奨、50% 未満で警告。
- NFR-3 プライバシー: 録音はローカル保存、全データ削除が可能、OS バックアップ無効(`allowBackup=false`)。
- NFR-4 UI: portrait 固定、RTL 対応、`largeHeap` 使用。
- NFR-5 多言語: 18 言語の UI と FAQ。
- NFR-6 必要権限: RECORD_AUDIO、FOREGROUND_SERVICE(microphone / mediaPlayback)、POST_NOTIFICATIONS、SCHEDULE_EXACT_ALARM、RECEIVE_BOOT_COMPLETED、READ_SLEEP(Health Connect)、位置情報(天気相関)、課金/広告/FCM 関連。
